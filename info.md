# Chargy – Price-Optimized Grid-Charge Planning

Plans when to pull grid power into a home battery by combining a normalized
electricity price curve, live battery state, learned household consumption
patterns, and an existing PV forecast into charge slots in the cheapest tiers
that cover the energy gap up to a configurable soft target SoC — no manual
scheduling and no hardcoded cutoff times; see the project's ADRs for the full
design.

**Status:** Brainstorming / concept phase – no working version yet.
